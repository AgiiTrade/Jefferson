# Deploy Directory

This folder is for publishable outputs and packaged assets.

## Keep Here
- PDFs ready to deliver or publish
- packaged bundles
- generated web assets
- deployment-ready files

## Do Not Treat As Source Of Truth
Strategy, workflows, plans, and operating docs should live in `active/`.

If a file exists in both `active/` and `active/deploy/`, the `active/` version should be treated as canonical unless the deploy copy is an intentional output artifact.
