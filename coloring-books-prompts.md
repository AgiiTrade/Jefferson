## 🎯 Image Generation Instructions

1. **Recommended Tools:**
   - Midjourney (v6 or higher)
   - DALL-E 3
   - Stable Diffusion with line-art models
   - Leonardo.ai or Artbreeder

2. **Prompt Tips:**
   - Always include "simple line art, thick black outlines, no shading"
   - Use "300 DPI" for print quality
   - Specify "white background" for clean coloring pages
   - Keep main characters large and centered

3. **Image Format:**
   - Save as PNG for transparency
   - 300x300 pixels for thumbnails
   - 800x800 pixels for full covers
   - Print-ready resolution: 300 DPI

4. **File Naming:**
   - `dinosaur-adventures-cover.png`
   - `under-the-sea-cover.png`
   - etc.

## 📦 Amazon KDP Preparation

### Image Requirements:
- Format: PNG or JPG
- Resolution: 300 DPI
- Size: Minimum 2500x2500 pixels
- File size: Maximum 50MB
- Color mode: RGB (for digital) or CMYK (for print)

### KDP Upload Process:
1. Create KDP account at kdp.amazon.com
2. Choose "Paperback" or "Hardcover" format
3. Upload interior PDF (your existing coloring-books.pdf files)
4. Upload cover image (generated images)
5. Fill in metadata:
   - Title
   - Author (your name)
   - Description
   - Keywords (coloring book, kids activities, children's book)
   - Category (Children's Activity Books)
   - Age range (4-8 years)
6. Set pricing ($4.99-$9.99 for print, $2.99-$4.99 for digital)
7. Preview and publish

### Marketing Tips:
- Use keywords: "coloring book for kids", "children's activity book", "educational coloring"
- Create social media content showing pages
- Offer free sample pages as promotional material
- Target parents, teachers, and gift buyers
